# Input Data

This directory contains the input sequencing/alignment data used for the DNA-seq variant calling workflow.

The actual BAM and FASTQ files are intentionally excluded from GitHub because of their large file size and data distribution considerations.

## Main dataset

- Sample: NA12878
- Input: NA12878.bam
- Target region: chromosome 11
- Reads: 101,003
- Primary mapped reads: 99,890
- Mapping rate: 100%

## Additional teaching data

E. coli and teaching FASTQ files were used for workflow practice and are also excluded from the repository.
