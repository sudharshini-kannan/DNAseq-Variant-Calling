# Reference Genome

The human variant calling workflow uses:

`Homo_sapiens_assembly38.fasta`

This is the Broad Institute hg38/GRCh38 reference used for the NA12878 analysis.

The reference FASTA and associated index/dictionary files are excluded from GitHub because of their large size.

Required files:

- Homo_sapiens_assembly38.fasta
- Homo_sapiens_assembly38.fasta.fai
- Homo_sapiens_assembly38.dict
